# Phase N 勘误记录

> **记录范围（AGENTS.md 瘦身策略）**：只记三类——
> ① 概念性错误（错误直觉会重犯的陷阱类，带证据与引用）；
> ② 独家复盘/分析（别处没有的内容）；③ 待修复/待审计登记。
> 机械性修复（行号/编号/typo/格式）只写 git commit message，不记这里。
> 修正错误时**必须同步修正原文**。自引用写"本章 corrections.md"，不带编号。
> 反复出现的陷阱蒸馏进 AGENTS.md「已知陷阱」或 README「陷阱与勘误」节。
